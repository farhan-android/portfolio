Who I am

The short version, and the fields that matter for a resume scan.

I'm an Android and Flutter developer working mainly in Kotlin and Dart. I build real applications, not tutorials — using Firebase, REST APIs, and interfaces that are meant to actually be used, not just demoed.

My biggest project so far is a zone-based fire monitoring system with collaborative decision logic between sensor zones, real-time alerts, and SMS notifications through Twilio. It's where I learned to think about state, timing, and failure cases, not just UI.

I'm now going one layer deeper: learning Node.js, Express.js, and PostgreSQL so I can build and reason about the backend services my apps talk to, instead of treating them as a black box.

I'm currently looking for an internship where I can contribute from day one and keep growing across the stack.

About Me

A bit about my journey

Mobile-first, backend-curious, and always shipping something real.

I'm an Android and Flutter developer working mainly in Kotlin and Dart. I build real applications — using Firebase, Firestore, and REST APIs — and I care about interfaces that are actually pleasant to use, not just functional.

My biggest project so far is a zone-based fire monitoring system with collaborative decision logic between sensor zones, real-time alerts, and SMS notifications through Twilio. It's where I learned to think about state, timing, and edge cases, not just UI.

I'm now going one layer deeper: learning Node.js, Express.js, and PostgreSQL with JavaScript so I can build and reason about the backend services my apps depend on, instead of treating them as a black box.

I'm currently looking for an internship where I can contribute from day one and keep growing across the stack.
